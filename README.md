**Data Structures & Algorithms – 3rd Semester Lab Work**

This repository contains my 3rd semester **DSA lab programs** implemented as part of the academic curriculum. It covers fundamental data structures and algorithmic techniques with practical implementations and problem-solving approaches.

### 📚 Topics Covered

* 🔎 Searching Algorithms (Linear Search, Binary Search)
* 🔄 Sorting Algorithms (Bubble Sort, Selection Sort, Insertion Sort)
* 🔗 Linked Lists (Singly, Doubly, Circular, Multi)
* 📦 Stacks (Array & Linked List implementation)
* 📬 Queues (Simple Queue, Circular Queue)
* #️⃣ Hashing (Hash Tables, Collision Handling – Chaining & Linear Probing)

### 🛠️ Purpose

* Strengthen understanding of core DSA concepts
* Practice algorithm design and implementation
* Analyze time and space complexity
* Build a strong foundation for advanced computer science subjects
